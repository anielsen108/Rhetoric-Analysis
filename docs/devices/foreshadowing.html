Foreshadowing

Planting details that quietly predict later events, legible fully only in retrospect. On first pass it tunes mood; on second pass it proves design. Foreshadowing converts a story into a structure — the ending was always already present, distributed through the beginning.

Romeo's "my mind misgives / Some consequence yet hanging in the stars."

Don't confuse it with Prolepsis. Prolepsis states the future outright; foreshadowing only seeds it. Chekhov's gun is its craft maxim.
